# 科研绘图台桌面版

Windows x64 首版，Electron 44.7.0。前端从同一份网站工作台源码构建，运行时完全使用打包资源，绘图无需网站服务器或外部网络。桌面专用 Origin / JADE 控件通过 Vite 别名替换，网站页面不受影响。

在网站根目录安装原有依赖，再到 `desktop` 执行：

```powershell
npm install
npm run runtime
npm run build
npm start
npm run package
```

输出为 `release/Friday-0.5.7-win32-x64/ScientificPlotStudio.exe` 及同目录的版本化 ZIP。构建时每版使用独立目录。首次安装请解压整个 ZIP，保留完整文件夹后运行 exe。

当前以桌面端为主要交付目标；除非用户明确要求，不再默认发布网页更新。

0.3.3 新增 Tafel 框选屏蔽、撤销/恢复、两条可拖动竖线选择拟合区间及不加权线性拟合。右侧显示截距、斜率与标准误差、SSE、Pearson r、R²和调整后R²；窄屏下方显示。每次只分析所选样品及扫描段，屏蔽按原始点序保留缺口；修改应用Rs、数据或区间后旧结果失效。完整CSV保留原始点与分析标记，可单独导出拟合统计/点/残差，SVG包含拟合线和结果表。

0.3.1 在软件顶部和“帮助”菜单增加“检查更新”。用户主动点击后检查 Gitee 的桌面发行版；发现新版本后可直接下载，软件自动核对各分片和完整 ZIP 的 SHA256。下载完成后选择重启安装，已导入数据尚未保存时会先提示保存或取消退出。更新器在程序退出后替换当前安装目录，在同级目录保留旧版备份，再启动新版；本机用户设置目录保留。软件不在后台定时检查或下载。

0.3.0 及更早版本没有更新入口，使用者需要手动下载一次 0.3.1 或后续完整桌面版。此后通过“检查更新”完成检查、下载和重启更新。发布者仍须增加独立桌面版本号，上传对应分片和 `release-manifest.json` 等全部附件后再公开新发行版，具体流程见 `docs/RELEASE.md`。

渲染进程启用 sandbox / contextIsolation，关闭 Node 集成和远程资源。预加载仅暴露指定的 Origin 导入、JADE 当前卡片读取、数据目录及菜单事件。主进程验证来源、UUID、包类型及资产路径，原有 Origin 严格校验与逐点回读保持不变。

桌面构建复制并适配已有连接脚本：Origin 直接读取本机生成的交接文件，JADE 将本次卡片结果传回本机临时文件，完成后删除传输文件。JADE 仍通过已验证的窗口复制按钮读取当前卡片，不访问或批量提取数据库。只在读取 JADE 时请求管理员权限。

Origin 中每次新建独立窗口和工作表；EIS 四列、LSV/XRD 完整原始列与绘图列继续沿用网站导出规则。JADE 当前仅适配已验证的 JADE 9 中文版。当前版本通过“保存项目”将工作数据和分析状态写入 .fri；未手动保存的工作可尝试从单个自动恢复副本找回；这不能代替正式保存和仪器原件备份。项目文件与仪器原件应分别保留。窗口大小、主题及最后工作台保存在本机用户目录。

构建只包含白名单应用文件和构建资源，不打包网站 `.env`、QA 数据、实验原件、标准卡数据库或卡片内容。
