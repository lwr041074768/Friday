# Friday

Current Electron desktop development preview: **0.6.0**, Windows x64. Nine local workbenches: LSV, overpotential, EIS, Cdl, CV/Ks, Tafel, pH dependence, XRD, and Raman. The EIS workbench shares imported spectra across Nyquist, potential-dependent contour, and Bode views. Bode supports magnitude/phase panels, individual panels, and explicit signed or negative phase conventions. Fri projects retain source data, sample groups, and plot settings.

Source: [GitHub](https://github.com/lwr041074768/Friday) and [Gitee](https://gitee.com/lwr2571166871/lwr). See the [Chinese README](README.md), [0.6.0 release notes](docs/RELEASE-0.6.0.md), [changelog](CHANGELOG.md), and [validation record](docs/VALIDATION.md). Download available binary assets from [Gitee Releases](https://gitee.com/lwr2571166871/lwr/releases), checking the version listed on that release. The current source is a 0.6.0 development preview. If split ZIP parts are provided, obtain all matching parts and the merge utility, verify SHA256, merge, and extract before running `ScientificPlotStudio.exe`.

The EIS workbench supports up to 80 spectra, retains signed imaginary values and source frequencies, and automatically screens 112 equivalent circuits with progress, cancellation, candidate ranking, circuit diagrams, and fit-report exports. Models may also be selected manually. Fit settings persist in Fri projects and results are recalculated on reopening. The [model documentation](docs/eis-zsimp-models.md) records definitions and implementation sources. CV/Ks supports scan selection, adjustable peaks, Laviron calculations, and per-scan exports; pH dependence supports sample groups, common-potential readings, and log j-pH fits.

Packaged binaries include their runtime. Imported data is handled locally. Optional OriginPro and JADE integrations use independently licensed local installations and the user's own reference data. Save a Fri (.fri) file to restore all nine workbenches' imported data, parameters, masks, fit ranges, axes, and floating BOOK windows after restarting. Preserve instrument originals separately. User-initiated update checks currently read Gitee releases; validated downloads can be installed on restart.

Build on Windows using Node.js 24.15.0: `npm ci`, `npm --prefix desktop ci`, `node desktop/install-runtime.mjs`, `npm run desktop:typecheck`, `npm run desktop:build`, then `npm run desktop:package`. Run `npm run desktop:check` for the verification suite. The bundled [offline PDF](docs/科研绘图台使用说明书.pdf) documents the historical 0.5.1 release; use the changelog and release notes for later additions.

The `src/` directory retains legacy browser standalone version 1.0.0, a separate release line from the current Electron app. This repository contains the standalone plotting application. Private server features, credentials, personal measurements, and licensed JADE card data stay in their respective systems.

[MIT license](LICENSE); [third-party notices](third-party/DEPENDENCIES.md) are retained. Users should verify reference electrodes, pH, temperature, active area, compensation history, fit ranges, and model assumptions when interpreting scientific results.
