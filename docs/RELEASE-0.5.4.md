# Friday 0.5.4 发行说明

发布日期：2026-10-18  
类型：桌面研发预览版（Windows x64）  
对应路线图：A-1 坐标轴、A-2 误差棒、A-3 注释层

## 新增

### A-1 坐标轴类型

- 倒数轴（1/x）：X、Y 均可选；范围不能跨 0，负值/零值跳过并在画布提示。
- Y 轴断轴：单断点，压缩中间区间；上下两段各自生成刻度，曲线、拟合线与注释在断口处裁切。
- 双 Y 轴：在“设置 → 双 Y 轴 / 上轴”里把曲线勾到右轴；右轴按当前 X 视窗独立自动缩放，右轴标题可改。
- 上轴/右轴独立刻度：上轴可填独立线性范围（留空则镜像 X 刻度）并单独命名；右轴为独立 Y 刻度。
- 缩放、悬停、框选、导出沿用同一套映射；设置随 .fri 保存。

边界：断轴仅支持 Y 轴、线性轴、单断点，不能与双 Y/对数/倒数同时使用；上轴独立范围是线性换算，不是第二套数据坐标。

### A-2 误差棒

- 过电位样品表新增“误差 ± / mV”列，可直接输入每个样品的误差。
- 柱状图绘制带端帽的误差棒，横向/纵向样式均支持；CSV 增加误差列。
- Cdl 多电极沿用每组标准差的误差棒，并在拟合线周围绘制 95% 均值置信带（近似）。
- 误差随 .fri 保存，导出 SVG/PNG/TIFF/PDF 保留。

边界：暂未加入 X 误差棒与通用“按列映射 Yerr”；Cdl 置信带为均值响应的近似带，不做预测带。

### A-3 注释层

- 共用画布新增“标注”菜单：文字、箭头、水平参考线、垂直参考线、峰值标注。
- 文字支持多行；可拖动、双击编辑、Delete 删除、清除全部。
- 峰值标注会吸附到点击处最近的数据点，并填入坐标。
- 注释随 .fri 保存，并进入 SVG/PNG/TIFF/PDF 导出。

边界：每图最多 200 条、每条最多 500 字；不做 LaTeX 公式排版，不做自动峰识别；颜色/字号暂用默认值。

## 项目格式

- `tickSettings` 接受 `reciprocal` 与 `break`。
- 新增 `annotations`、`axisAssignments`、`y2Label`、`topLabel`、`topMin`、`topMax` 图级字段。
- 旧 0.5.3 项目继续可读，缺省字段自动补；保存后仍可被 0.5.4 打开。
- Origin 模式原型不进入 0.5.x 主线；主界面保持七个电催化工作台。
