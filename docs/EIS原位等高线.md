# EIS 原位等高线

在 EIS 页面标题下切换 **Nyquist / 原位等高线**。

点击“导入数据”，在导入窗口选择多个文件或“导入文件夹”。支持同一批次最多 80 条谱线，文件夹按来源目录区分样品组；曲线下方可修改样品组和测量电位。文件名如 `EIS-0.43V`、`EIS-0.510` 可识别电位，未知电位可手工填写。频率列可选择，并支持 Hz、kHz、mHz、MHz。

横轴为 `log10(f / Hz)`，纵轴为实测 `Potential / V`，保留不规则电位间隔。颜色默认 `log10(|Z''| / Ω)`，也可选择 `log10(|Z| / Ω)`。每次显示一个样品组，采用各谱共同频率区间，在 log-frequency 轴上线性插值显示；原始点和有符号虚部继续保存。相同电位的重复测量可择一显示，零值与缺失点形成显示缺口。

“导出原始数据”包含全部组、隐藏谱线、每个原始点、频率、来源、电位及有符号虚部；“导出网格”保存当前组的显示插值网格。支持 SVG、PNG、TIFF、PDF。分组、电位、图形模式、配色、坐标范围及刻度随 `.fri` 保存。

Nyquist 继续使用正方形绘图区与右侧单列图例，保留等效电路拟合和 112 模型自动选优。


公开合成验证：`node scripts/verify-eis-contour.mjs`。
