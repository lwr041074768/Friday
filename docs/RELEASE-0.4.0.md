# 0.4.0 电催化科研工作台：研发版本记录

本版是“科研绘图台”的桌面研发预览版，包含项目管理与统一界面。显示名称沿用科研绘图台，英文副标题为 ELECTROCATALYSIS STUDIO；内部产品标识、更新源与用户设置目录保持既有约定。

## 本版实现

- 顶部项目操作栏、左侧七个工作台导航和独立配色、卡片编排；保留用户要求的浮动 BOOK（A/B、空 C、D/E）。
- 本地 .ecproj 项目文件。保存的是导入后的数据与分析状态；不需要再次寻找原始文件即可恢复已保存的工作数据，仪器原件仍单独保留。
- 参数草稿与已应用值分别保存，NaN/无效点保留缺口；恢复时重新计算图形和拟合，不把旧统计表当作不可核验的结论。
- 撤销/重做、未保存提示、数据格式验证和本机文件替换写入。

## 研发归档内容

源码提交和构建时间以发行包 VERSION.json 为准；同版 Source.zip 来自对应 Git 提交。用户手册含 Markdown、PDF 和模拟数据界面截图；数值与桌面验证记录在 VALIDATION.md。现有 LICENSE、third-party/DEPENDENCIES.md、第三方许可与署名文件继续保留。

本记录仅描述本版研发成果及归档位置，不填写软件著作权人、开发主体、首次发表时间或登记编号，也不代表已经提交软件著作权申请。后续资料中的主体信息和登记要求需另行确认。
