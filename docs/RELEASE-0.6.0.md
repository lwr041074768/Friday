# Friday 0.6.0

EIS 页面支持同一批数据的三种视图：**Nyquist、原位等高线、原位 Bode**。样品组、测量电位、颜色、可见性与原始数据共用，切换视图即可查看。

原位 Bode 默认显示上下两张图：上图为阻抗模值 `|Z| / Ω`，下图为负相位角 `−φ / °`，频率为对数轴。左侧可切换为相位或模值单图，并选择原始相位 `φ`。图例按实测电位排序，悬停显示原始点序、频率、模值、相位及来源。

计算使用导入的实部与有符号原始虚部：

- `|Z| = hypot(Z′, Z″)`
- `φ = atan2(Z″, Z′) × 180 / π`
- `−φ = −atan2(Z″, Z′) × 180 / π`

导入列若已标为 `−Z″`，先按其约定还原 `Z″`。原始虚部及感抗段符号保留。缺失点保留断线，零阻抗点保留原始记录；模值对数轴和相位采用各自有效点。

频率范围、相位范围、模值范围和刻度可分别设置，支持复位、全屏、完整CSV以及SVG/PNG/TIFF/PDF导出。CSV保留全部样品组、隐藏曲线、原始点和两种相位定义；`.fri` 保存视图、显示方式、相位符号和图形设置，并兼容0.5.8项目。

桌面主程序、界面、预加载接口、依赖锁文件和发行包版本统一为 **0.6.0**。

参考：[Gamry — Basics of Electrochemical Impedance Spectroscopy](https://www.gamry.com/application-notes/eis/basics-of-electrochemical-impedance-spectroscopy/)，Bode以频率展示阻抗模值与相位。
