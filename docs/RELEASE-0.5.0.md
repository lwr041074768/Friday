# Friday 0.5.0：Fri 项目与统一图形设置

保存类型和默认后缀改为 Fri（.fri）。仍可打开旧 .ecproj，旧项目常规保存时建议新建 .fri 副本，取消不改旧文件；新格式沿用既有无损数据编码与项目 schema。

七个工作台采用 LSV 式左右布局。坐标范围、主次刻度集中到“设置”；Cdl 的 CV 与拟合图、Raman 的线图与等高线各自保留设置。Raman 的显示范围真正变换图形视口，悬停读数映射回源网格；不把改刻度标签当作图形裁剪，也不改写源网格、拟合样品或原始数据。

设置窗口在 BOOK 上方显示，全屏图形也可使用；原生工作台快捷键在设置打开时暂缓切换。仅允许可信本机主页面请求有用户手势的图形全屏，其他页面和其他权限继续拒绝。

按用户授权调用官方 DeepSeek API 的 deepseek-flash（2026-10-18 核对为 DeepSeek-V4.1-Flash-1017）协助生成共享设置窗口，并审查复杂交互边界。返回内容经本地代码审查、修正和实际测试后集成，不接触 API 密钥或实验数据。[官方更新日志](https://api-docs.deepseek.com/updates/)

本机软件包、Source.zip、说明书和 SHA256 依照同一源码提交准备；未在此过程公开上传至 Gitee。实际验证项目见 VALIDATION.md。
