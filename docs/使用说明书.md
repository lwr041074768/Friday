# Friday 使用说明书

Windows 桌面版 0.5.1 · 电催化工作台预览版

适用模块：LSV、过电位、EIS、Cdl、Tafel、XRD、Raman。

编制日期：2026-10-18。本文以 0.5.1 桌面版为准，不适用于旧版“启动本机服务后在浏览器打开”的独立版。

源码与发行版：https://gitee.com/lwr2571166871/lwr

本软件在本机导入、计算和导出。Origin 与 JADE 是可选的外部软件，须由使用者另行合法安装。

本说明书中的界面均使用明确构造的模拟数据，供操作演示，不代表实际材料性能或实验结论。

软件现名 Friday（原名科研绘图台）。图形设置截图更新为 0.5.1，其余工作台与 BOOK 截图沿用 0.5.0 界面；数据均为构造示例。0.4.0 新增项目保存与恢复，请先阅读第 02 节。

# 01 安装、启动与升级

解压整个 Windows x64 压缩包，然后运行 ScientificPlotStudio.exe。普通使用不需要另装 Node.js 或 npm；请保留完整文件夹，不要只复制 exe。

如果发行版提供的是 .zip.001、.zip.002 等分片，先下载同一版本的全部分片及合并脚本，放在同一个文件夹，按发行说明合并并核对 SHA256 后，再解压生成的完整 ZIP。不要混用不同版本分片。

首次启动时有可跳过的动画。进入软件后，在右上角核对版本号。左上角可切换白天和夜晚模式；科学图纸和导出图形保留白底。

首次升级：0.3.0 没有检查更新功能，须先从发行页下载 0.3.1 或更新版本，导出需要的数据并完全退出旧版本，再解压并从新版文件夹启动。程序采用单实例运行，旧版仍打开时，双击新版可能只是唤回旧窗口。

从 0.3.1 起，可点击顶部“检查更新”或“帮助 > 检查更新…”。软件只在你主动检查时联网获取版本信息，不定时检查。发现新版后点击“下载更新”，软件会自动下载全部分片、合并更新包并核对分片和完整包的 SHA256，无需手动合并。

下载完成后点击“重启并更新”。如果还有需要保留的绘图数据，请在确认窗口取消，先保存项目或导出需要的数据，再重新确认更新；软件不会代替你确认保存。确认后会在后台准备文件，完成后关闭、替换并重新启动软件。准备期间请等待，不继续编辑数据。

更新保留原程序路径，旧程序文件夹留在同级的“原文件夹名.backup-…”目录。下载和准备更新需要可用网络、足够磁盘空间及程序目录写入权限；出现错误时按提示重试。不要把程序备份目录当作当前绘图数据的项目备份。

工作台数据先保存在运行内存中。点击“保存项目”写入 .fri 后，才能在重启后恢复；始终保留原始仪器文件。图形和单独数据表的导出不能代替完整项目保存。

# 02 项目、导航与保存

顶部项目栏可以命名、新建、打开、保存和另存为项目。Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+Shift+O 打开项目；Ctrl+O 仍是导入当前工作台数据。

保存类型为 Fri，默认文件后缀为 .fri。旧版 .ecproj 仍可打开；保存旧项目时会建议生成同名 .fri 副本，原文件保留。取消保存不会替换当前项目。

.fri 保存已导入的数据列、IR 草稿及已应用值、扫描方向、屏蔽点、拟合区间、坐标范围与刻度、各工作台设置以及 BOOK 窗口。项目内包含数据副本，但不是仪器原始文件的完整备份，仍应保留原件。Tafel 拟合在恢复时依据保存的数据重新计算和检查。

项目有修改时显示“未保存”。切换到另一项目或新建前，软件会提示未保存的修改；打开无效项目会保留当前数据。退出前请确认保存完成。需要复制一份独立文件时使用“另存为”。

左侧是 LSV、过电位、EIS、Cdl、Tafel、XRD、Raman 七个工作台。Ctrl+1～5 对应 LSV、EIS、Tafel、XRD、Raman；Ctrl+6 过电位，Ctrl+7 Cdl。过电位由 LSV 数据联动计算。

项目栏的撤销、重做可恢复本次运行中的分析参数和视图操作。在普通输入框外，Ctrl+Z 撤销分析，Ctrl+Shift+Z 重做；输入框内保留文字编辑行为。修改框中的 IR 尚未确认时，不会提前改变计算数据。

导入前核对列映射、单位和实验条件。支持的仪器 BIN 仅限已验证格式，OPJU 需先在 Origin 导出数据。项目恢复保留已导入的数据与缺口，不代表已经核实参比、面积、pH 或模型适用性。

# 02A 数据 BOOK

LSV 和 Tafel 的每个样品下方有 BOOK 与“+”。点击“+”添加，同一样品最多 10 本，包括已隐藏的窗口。多个 BOOK 共享同一样品的当前数据，可分别移动和查看。

BOOK 只有四个数据列：A(X1)、B(Y1) 是导入的原始电位、电流；C 整列留空；D(X2)、E(Y2) 是计算后的 X、Y。左侧行号独立，不算数据列。A/B 保留原单位和数值，不随 IR 改写；D/E 在点击“确定”应用 IR 后与曲线一起同步，尚未确认时保持旧值。

新 BOOK 默认是浮动子窗口。直接拖标题栏移动，拖右下角调整大小；标题栏按钮可最小化、展开、最大化及还原，双击标题栏也可最大化/还原。关闭仅隐藏，点击样品下的 BOOK 编号可重新打开并保留位置。底部垃圾桶可确认移除此视图，释放名额，不删除样品数据。

单击选择单元格，Shift+单击扩选，Ctrl+C 或复制按钮保留完整精度；Ctrl+A 全选。底部“原始行”可跳转，CSV 同样按 A/B、空白 C、D/E 导出全部原始行，不只包含可见部分；缺失或计算无效的值留空。保存项目可保留数据、计算参数和 BOOK 的位置、大小及开关状态；未保存的修改仍只存在本次运行中。

# 02B 图形设置

各工作台按左侧参数、右侧画布排布。点击画布上方“设置”，集中调整 X/Y 轴范围、轴类型、主刻度与次刻度；修改后点击对应“应用”按钮，关闭后继续分析。

X、Y 轴可分别选择“线性”或“对数（10 的幂）”。对数轴按 10 的整数次幂生成主刻度、按 2–9 生成次刻度，主刻度间隔、锚点和次刻度数量不适用；轴范围必须大于 0。数据中的 0 和负值在对数轴上不显示，画布上方会说明被跳过的点数，曲线在缺口处断开，原始数据不改动。切换轴类型会清除该轴此前的手动范围和缩放；项目会保存轴类型与范围。Cdl、过电位与 Raman 等高线页目前仍为线性轴。

每个轴的最小值和最大值需成对填写，且最小值小于最大值。恢复自动范围会重新显示完整图形。主刻度间隔留空为自动，锚点决定刻度起点；次刻度数量为相邻主刻度间的短刻线数，允许 0～20。非法或过密刻度会提示原因，不替换已应用设置。

Cdl 可分别设置 CV 与拟合图；Raman 线图和等高线各自保留设置，光谱截取范围也在此窗口。Tafel 的红线拟合区间仍通过画布分析工具选择，与坐标显示范围分别管理。更改图形坐标不会改写仪器原始数据或替代重新选择拟合区间。

# 03 LSV 操作

点击“导入数据”，选择文件，核对原始电位和电流列，再确认绘制。可修改样品名、颜色、显示状态，切换正向、反向或全部扫描，并用曲线旁的撤销恢复误删。

当前固定公式为 X = 第一列 - iR * B1 + 0.059 * 13.65 + 0.197，Y = 第二列 * 1000，其中 B1 表示原始第二列数值。公式不会根据列单位自动重写。

每条样品的 IR 先填写，再点击确定应用。未确认的输入不改变曲线。导入源文件已做补偿时，应避免再次扣除；请核对实际补偿方式和当前公式，不能把界面里的 IR 名称直接等同于所有仪器的同一种参数。

软件按当前已应用曲线读取 Y=10 的交点，并尽可能绕过前面的阳极氧化峰。候选或多重交点需要人工核对完整曲线；选错扫描方向、混入不同循环或只有氧化峰时，读数不构成可靠 OER 指标。

重要：只有电位已按正确参比条件换算为 RHE、Y 确实为 mA/cm2 时，(X@10 - 1.23)*1000 才能解释为相应的 OER 过电位。默认 pH 和参比常数不代表软件已经核实你的实验条件。

# 04 过电位比较

过电位页直接读取 LSV 页的样品名称与当前读数。先完成 LSV 的列映射、单位、IR 与扫描段检查，再到这里比较。修改 LSV 的名称或读数后，这一页会同步更新。

可切换柱状图样式，设置坐标范围、主刻度与次刻度。样式不改变原始交点或已应用 IR。缺少有效读数的样品会保留状态说明，不能把空值当作 0 mV。

数据、图形和 Origin 导出沿用同一批读数。导出前确认样品顺序和候选状态；不要仅凭柱高直接下材料优劣或显著性结论。

# 05 EIS：符号和单位

导入时选择实部 Z' 与虚部列。若第二列为原始 Z''，绘图使用 -Z''；若导入列已经是 -Z''，保持该列，不再取负。请根据文件表头和仪器设置核对。

图中出现负的 -Z'' 并不自动说明数据读错：原始高频感抗段的 Z'' 可以为正。软件保留正负号，不取绝对值。

单位可核对为 ohm、kohm 或 mohm 并换算。频率只在原文件可识别且单位明确时保留，缺少时不补造。缺失行作为图中的断点保留。

可导出完整数据、当前 SVG，或传入 Origin。Origin 每组保留原始实部、导入虚部、绘图实部和绘图 -Z'' 四列。当前没有自动等效电路拟合、Rct 计算或由半圆大小生成样品排名的功能。

# 06 Cdl：从扫速文件到拟合

先选择左侧第一组至第十组中的一组，点击导入，一次选择该组全部扫速文件。仪器头部扫速、文件名扫速和单位应一致；发生冲突或缺少信息时，按提示核对，不要凭文件顺序猜扫速。

每个独立电极应保留独立目录和身份。软件可分别拟合，再统计均值与样本标准差；多个扫描速率不等于多个平行电极。不要把不同材料放入同一组后当作平行样统计。

选择不含明显法拉第反应的取点电位 E0，确认正扫和反扫都覆盖它。默认 0.075 V 仅是初始设置，不保证适合你的体系。面积留空时为总电容；填入正确面积后可得到面积归一化结果。

默认取 (Ia - Ic)/2 随扫速拟合。若纵轴是 mA、横轴是 mV/s，则 Cdl(mF)=斜率*1000；若采用全差 Ia-Ic，则同一电容须再除以 2。界面会随所选方案计算，不能混用公式。

拟合图、取点表和 Origin 导出使用相同的选圈规则。默认末个完整圈，可在设置中检查。R2 高不等于电位窗口一定没有副反应；应先看 CV、取点窗口和扫速范围。

# 07 Cdl：结果与导出

组名旁的铅笔可重命名；名称会同步到图例和导出。当前组与十组结果视图可用于检查组内拟合和不同组的汇总。

“导出本组”支持数据表、Excel、完整原始 CSV、SVG，以及直接导出至 Origin。Origin 可创建可编辑的 CV 与 Cdl 拟合图，并保留对应工作表。完整原始 CSV 包含原始圈；所选圈和拟合结果在相应导出表中另有标记。

检查五件事：扫速单位是否为 mV/s 或 V/s；电流单位是否正确；E0 是否在双向扫描的共同区间；选中了哪一圈；面积和独立电极数是否真实。

说明：Cdl 不能在缺少合适比电容 Cs 和适用前提时直接换算成可靠 ECSA，也不能单凭 Cdl 大小证明某个反应机理。

# 08 Tafel 操作与限制

左侧设置公式、横轴口径和 Rs，右侧为方形画布。曲线管理在左侧空白区，空间不足时放到下方；“坐标标题”可展开。

横轴为 log10(abs(I*1000))（I：A）或 log10(abs(j))（j：mA/cm2，需面积）。纵轴为 E - Rs*I + 0.0592*13.65 + 0.197 - 1.23，单位 V；Rs 单位 ohm。单独 Rs 留空时跟随全局，修改后按“确定”。跨页比较需核对参比、pH、温度及换算常数。零电流保留为缺口，导出保留原电流正负号。

先选“分析样品”和扫描方向，再点“框选屏蔽”并拖动矩形。仅屏蔽所选样品框内的点，保留断点与原始数据；可撤销屏蔽或恢复全部。

点“选择拟合区域”，左右拖动两条红线，或输入精确上下限；再点“线性拟合”。结果放在右侧空白区，窄屏放到下方。使用不加权 y=a+b*x，至少需要3个未屏蔽点和不同X；正反扫混合时须先选方向，正负电流混合时须先屏蔽不需要的分支。斜率保留正负，V/dec乘1000得到mV/dec，±为1个标准误差。更改应用Rs、数据、区间或扫描选择会清除旧结果。

完整CSV保留原始点、屏蔽/拟合标记、Rs与统计。“导出拟合结果”另含所选点、预测值和残差，SVG包含拟合线与结果表。区间由使用者确认，高R²本身不证明选中了合适的动力学区域。

# 09 XRD 与 JADE

导入 2theta 和强度，选择叠加、堆叠或归一化，检查波长与横轴单位。曲线显示范围、样品隐藏和显示抽稀不会替代完整原始数据导出。

JADE 连接针对本机 JADE 9 中文版当前打开的一张卡片详细窗口。先在 JADE 打开卡片，再点击“从 JADE 读取”；Windows 要求同等权限时按本机策略处理。只读取当前卡片，不批量提取或发布数据库。

最多保留 20 张卡片，同时显示最多 6 张峰棒。修改显示波长会换算峰位，不改变原卡片强度。卡片与实验峰重合只能作为物相比对依据之一，不等于自动完成定相。

源码和发行包不包含 JADE、PDF 标准卡数据库或授权。没有打开可用卡片、版本不匹配或窗口不可访问时，读取可能失败；仍可正常使用实验谱图和数据导出。

# 10 Raman 导入与分组

Optosky 六列文本默认选 X=第 2 列 Raman Shift，Y=第 6 列 BaseLine Subtracted。后者是仪器已经扣基线的列，不等同于原始探测器强度。可在导入窗口改选 Raw 或 Dark Subtracted。

Pixel 是像素编号，不能作为拉曼位移。若曲线成为几条近似直线，优先检查是否误把 Pixel 与 Raman Shift 作为 X/Y，而不是直接解释为样品没有峰。

选择文件夹可保留子文件夹分组；例如 NEW 与父文件夹分别管理。可改变名称、颜色、显示状态和顺序，不自动合并干态、湿态或重复测量。最多保留 80 条光谱。

文件名 01、035、055 等只生成待核对的电位建议，不是仪器参比证据。dry、wet 不自动赋电位，也不自动改为 OCP。使用真实电位纵轴前，核对电位值及参比。

# 11 Raman 堆叠、等高线与导出

堆叠间距只平移显示；0 表示叠加。按每条曲线最大绝对值归一化会改变不同光谱的相对强度比较，应与保留原始强度的结果区分。

等高线每次显示一个数据组。序号轴按列表顺序排列；电位轴按数值排序，并排除未知电位。相同电位的重复测量须先择一或改用序号轴。

显示仅在光谱共同位移区间内做线性插值。色块和光滑边界是显示结果，不能作为新增测量点，也不自动构成峰位移动、价态变化或机理证据。

左侧导入数据并切换图形；画布顶部集中放置导出数据、导出图形 SVG 和设置。“导出数据”菜单可保存本组 CSV，或“导出数据至 Origin”。Origin 包含原始位移、所选列原始强度、绘图位移和绘图强度，保留隐藏光谱及原始行；等高线模式导出光谱数据，不把显示插值当作实测值。

# 12 Origin 连接与可编辑数据

本机须合法安装、激活 Origin 或 OriginPro，并具备可用 COM 接口。已验证环境为 OriginPro 2024；其他版本应先用少量文件验证。桌面版内置连接程序，不需要额外安装网页助手。

点击相应页面的 Origin 导出，等待写入与读回核对结束。软件在独立的新窗口或工作簿中写入数据，不覆盖已有实验项目。完成后仍须在 Origin 自行保存 OPJU。

LSV、EIS、XRD 以完整工作表数据导入；Raman 通过导出数据菜单导入当前组；过电位与 Cdl 可生成相应可编辑图。Tafel 当前提供 CSV/SVG，可把 CSV 手动导入 Origin。

一般每次向 Origin 导出最多 500,000 个原始点，超出时分组。原始列与当前绘图列分开保留，后者不要在 Origin 中重复做一次相同 IR、归一化或堆叠处理。

如果提示连接忙，先等待当前任务结束。失败时查看应用提示和本机数据目录中的日志。交接文件和日志不是原始实验文件的完整项目备份。

# 13 常见问题排查

导入后没有曲线：检查文件格式、数值分隔符、列映射、单位，以及是否选了错误扫描段。Excel 公式没有缓存值时，先在 Excel 重新计算并保存。

曲线中间断开：可能是缺失值、零电流对数无效或不连续扫描段。软件会保留内部缺口，不应为了画成连续线而自动填 0 或跨过缺口连接。

LSV 的 eta10 异常：检查氧化峰是否造成早期交点、是否属于所选扫描方向、IR 是否已重复应用、电位是否确为 RHE、电流是否确为所需密度。

Cdl 没有拟合：检查至少两个不同且有效的扫速、E0 处的双向覆盖、完整循环、原始单位，以及是否混入不同材料。不要把一份已经平均的曲线重复计作多个独立电极。

Origin 导出失败：先在本机单独打开并确认许可，核对 COM、位数和权限，再尝试少量数据。JADE 失败：核对 9 中文版、当前卡片详细窗口和权限，避免在没有卡片时反复读取。

重新打开仍是旧版：完全退出旧进程，从新版目录或更新后的桌面快捷方式启动，并核对右上角版本号。
