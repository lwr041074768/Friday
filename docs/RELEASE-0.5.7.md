# Friday 0.5.7 模块独立 / 轴简化 / Origin 画布

日期：2026-10-18。本版只做结构性整理和画布风格，不新增分析模块。

## 同版本交互修复（版本号保持 0.5.7）

- 注释删除与方向键仅由获得焦点的可见画布处理；切页、设置输入和 BOOK 操作不会误改其他图。
- “标题”页新增 X/Y 显示文字、字号和加粗，保留拖动、默认标题恢复与位置复位；仅改变展示，不改变原始单位或计算。新字段随 `.fri` 保存，旧项目缺少这些字段时使用默认样式。
- 设置分页支持 Tab、左右方向键、Home/End；Esc 关闭后返回原来的设置按钮或轴标题，全屏内仍可使用。
- 标题按实际字体测量并限制在画布内；缩放窗口只调整显示。BOOK 也按窗口临时适配，不覆盖保存的位置。
- SVG/PNG/TIFF/矢量 PDF 共用当前画布的文字样式；旧的直接 SVG 导出入口同样处理，导出中去掉选中高亮和编辑手柄。
- 新增 9 项真实窗口交互验收；38 项脚本检查、20 项项目流程、3 组实际图形导出均通过。具体路径见 `VALIDATION.md` 顶部。

## 模块独立

- 新增 `app/modules/`：`lsv.tsx`、`overpotential.tsx`、`eis.tsx`、`cdl.tsx`、`tafel.tsx`、`xrd.tsx`、`raman.tsx` 各自导出模块定义。
- `app/modules/index.ts` 是唯一注册表；`types.ts` 定义模块 ID、运行上下文和 `render` 契约。
- 桌面外壳 `desktop/renderer/main.tsx` 只依赖注册表，不再直接 import 七个工作台，也不维护标签/图标/面板三元表达式。
- 本版是“外壳与模块边界”的第一步；各模块内部仍复用现有工作台实现，后续可逐个迁移到独立目录而不改外壳。

## 轴简化

- 通用画布的轴类型选择器去掉“对数（10 的幂）”，只留“线性”和“倒数（1/x）”。
- 旧 .fri 项目若已保存对数轴，设置中只显示“对数（旧项目，建议改回线性）”；新图无法再选择对数。
- 断轴、双 Y 轴、上轴独立范围和右轴刻度全部保留。
- Tafel 的 `log₁₀|j|` 横轴和 EIS 原位数据的 `log₁₀(f)` 是方法/数据固定轴，不依赖通用轴类型选择器。

## Origin 风格画布

共用线图画布（LSV、Tafel、EIS、XRD、Raman）改为：

- 方形黑色外框，主/次刻度向内；
- 去掉背景网格；
- 轴标题黑色加粗，刻度标签黑色；
- 图例改为不透明白底、细黑边框、直角；
- 画布面板改为浅灰工作区、直角、无阴影；工具栏改为浅灰白底；
- “交互画布”小标签隐藏，只留图形标题。

## 画布交互（Origin 式）

- X/Y 轴标题可直接拖动；双击轴标题打开设置“标题”页，双击坐标轴或主刻度打开“坐标轴”页。
- 设置弹窗按“坐标轴 / 标题 / 注释”分页；“坐标轴”页始终包含数值范围输入，LSV、EIS、XRD、Raman 线图都可直接改范围。
- 文字注释可右键显示/隐藏边框，也可在“注释”页切换。
- 箭头注释可在“注释”页修改线宽和箭头大小。
- 水平/垂直参考线、文字、箭头选中后可用方向键微调：1 px；Shift 0.1 px；Ctrl 0.01 px；Alt 10 px。新建注释会自动选中。
- 注释属性随 .fri 保存；轴标题偏移同样随项目保存。

注释、断轴、双 Y、悬停、缩放、导出映射不变。
