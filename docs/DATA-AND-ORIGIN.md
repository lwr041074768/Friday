# 数据与 Origin

当前桌面版 0.3.0 的完整流程见 [使用说明书](使用说明书.md) 和 [PDF](科研绘图台使用说明书.pdf)。

原始数据与当前绘图数据分列。归一化、IR、堆叠、可见状态和文件来源写入相应备注；完整导出不按显示范围裁剪或抽稀。缺失值保留为空值或图中断点，不补造 0。

桌面版内置连接程序，用户另行合法安装 Origin / OriginPro 后即可导出。普通绘图不需要 Origin；Tafel 当前通过 CSV 手动导入。Raman 的入口在“导出数据 → 导出数据至 Origin”。Cdl 和过电位可以创建可编辑图；其他页面主要创建可编辑工作表。

Origin 中创建独立数据窗口，完成后仍须保存 OPJU。旧浏览器独立版 1.0.0 使用可选网页助手，属于不同部署方式，不要把它的安装确认与桌面版实际导入完成混为一谈。

程序、源码和发行包均不分发 Origin、JADE 或标准卡数据库授权。
