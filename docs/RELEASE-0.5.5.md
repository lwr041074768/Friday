# Friday 0.5.5 发行说明

发布日期：2026-10-18  
类型：桌面研发预览补丁版（Windows x64）

## 交互修正

### 图内标注改为右键菜单

在任意共用画布（LSV、Tafel、EIS、XRD、Raman 线图）上**右键**，弹出 Origin 风格菜单：

- 文字：在右键位置放置，输入后回车；
- 箭头：选择后在图上从起点拖到终点；
- 水平参考线 / 垂直参考线：在右键位置立即添加；
- 峰值标注：吸附到右键附近最近的数据点，预填坐标；
- 删除所选 / 清除全部。

原工具栏“标注”按钮已移除。右键菜单外的点击、Esc 会关闭菜单。注释仍支持拖动、双击编辑、Delete 删除，随 .fri 保存并进入 SVG/PNG/TIFF/PDF。

### LSV 曲线管理精简

- 移除 LSV 曲线卡片中的“原始单位”下拉。
- 移除“电极面积 S / 原数据补偿状态”详情块。
- Tafel 页**保留**原始单位、电极面积与补偿状态，因为电流密度换算与重复补偿校验仍需要这些字段。
- 导入时设置的单位、面积与补偿状态仍保存在曲线中，计算不受影响。

## 验证

- 右键菜单添加文字、水平参考线、箭头共 3 条注释，无页面错误。
- LSV 面板：`原始单位` 0 个、`面积` 0 个；Tafel 面板：两者各 3 个（3 个示例样品）。
- 右键添加的注释可拖动；保存 .fri 后重开恢复；导出的 SVG 含注释文字与节点。
- 14 项界面流程、35 项脚本检查继续通过。
- 安装包 `app.asar` 内 `package.json`/`preload.cjs` 均为 0.5.5，快捷方式已指向 0.5.5。
- 当前 0.5.4 仍在运行，安装版启动冒烟未执行；关闭旧版后运行即可。

## 边界

- 右键菜单只作用于共用线图画布；Raman 等高线、Cdl 双图、过电位柱图仍不支持图内注释。
- 箭头为两点拖拽，不支持折线箭头或旋转手柄。
- 说明书 PDF 仍为 0.5.1，按约定在 Gitee 发行时统一重建。
