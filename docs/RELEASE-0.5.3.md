# Friday 0.5.3：出版导出、EIS 拟合、Tafel 自动区、工作表与恢复

本版对应优化路线图“当前基线”中列出的五项缺口，按 A-8、C-1、C-2、B、D-1/D-2 的顺序完成。

## 出版级出图（A-8）

图形设置之外的“导出图形…”支持 SVG、PNG、TIFF 与 PDF。宽度以毫米填写（20–1000 mm，常用 85/120/160/190），高度按图形比例自动计算；位图分辨率 150/300/600/1200 dpi；PNG 与 TIFF 可选透明背景。PDF 页面按毫米排版，内嵌 JPEG；TIFF 为无压缩 RGB/RGBA，带 dpi 标签。导出暂存覆盖 LSV、EIS、Tafel、XRD、Raman 线图、Cdl 双图、过电位与 Raman 等高线；原 SVG 按钮保留。

## EIS 等效电路拟合（C-1）

支持 Rs+(Rct∥CPE)、含 Warburg 的 Randles、双时间常数三种电路，modulus（按 |Z|）或 unit 加权。最小二乘使用数值雅可比与 Levenberg–Marquardt，参数经正变换与 n∈(0,1) 约束。结果显示参数 ± 标准误差、χ²、总电阻、残差 RMS、点数/自由度与迭代次数，并在 Nyquist 图上叠加拟合曲线（仅显示，不写入数据导出或项目）。拟合需要频率列；少于 5 个带频率的有效点会说明原因。数值精度收敛（χ² 达到数据尺度的 1e-16）按已收敛处理。

## Tafel 自动线性区与 j₀（C-2）

“自动选区”在所选样品与扫描方向上扫描窗口，按 R²、区间长度与点数评分，选出最佳线性区并可继续手动调整。拟合结果新增交换电流密度 j₀ 与斜率 95% 置信区间；t 分位数为双侧 Student-t。自动选区要求先选择正向或反向扫描，避免混合两支数据；无效点或过短区间会给出原因。

## 数据表工作表（B）

BOOK 新增最多 4 个公式计算列，可用 a（原始电位）、b（原始电流）、x（当前 X）、y（当前 Y），支持 + − * / ^、sqrt、log10、ln、abs、exp；计算列不改原始 A/B，随 BOOK 保存并包含在 CSV 导出中。新增列统计（n、均值、标准差、最小、中位数、最大）。容量提高为每页最多 20 条曲线、文本数据表最多 20 万行，CSV/Origin 导出上限同步。

## 自动保存与撤销（D-1/D-2）

有未保存修改时，每 60 秒及窗口隐藏时写入 `%APPDATA%\ScientificPlotStudio\Recovery\autosave.fri`。异常退出后再次启动会提示“发现未保存的自动恢复副本”，可恢复或忽略并删除；手动保存、新建或打开项目后清除。撤销保留从 40 步提高到 120 步。

## 边界

- 等效电路拟合不替代物理判断；Rct/CPE/Warburg 需结合模型与实验条件核对。本版未加入 Bode 图、Kramers–Kronig 校验与 DRT。
- Tafel 未加入 120/40/60 mV/dec 判据线与多区间对比；自动选区超过 4000 点时降采样。
- 工作表只允许新增计算列，原始 A/B 保持只读；排序、平滑、基线、峰积分与微分/积分尚未实现。
