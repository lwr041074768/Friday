# Friday 0.5.1：坐标轴类型

图形设置新增 X、Y 轴类型：线性与常用对数（10 的幂）。LSV、EIS、Tafel、XRD 与 Raman 线图共用的画布同步支持；Cdl、过电位与 Raman 等高线仍为线性轴。

对数轴按 10 的整数次幂生成主刻度，次刻度为 2–9，因此主刻度间隔、锚点与次刻度数量在对数模式下不适用，界面上相应禁用。0 和负值在对数轴上没有位置：这些点不绘制，曲线在原位置断开，画布上方说明被跳过的点数，源数据不变。对数轴的范围必须大于 0，非法范围会提示且不替换已应用设置。

切换轴类型会清除该轴此前的手动范围和缩放，避免把线性坐标下的范围套用到对数坐标。轴类型与手动范围随 .fri 项目保存与恢复。

本次是 0.5.x 的一个小步，未包含倒数轴、断轴、双 Y 轴与上/右独立刻度；这些仍属于“坐标轴类型”这一项的后续部分。检查记录见 [VALIDATION.md](VALIDATION.md)。
