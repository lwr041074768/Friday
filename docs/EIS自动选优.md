# EIS 全模型拟合

导入含频率、Z′ 与 Z″ 的 EIS 数据，在“等效电路拟合”中选定样品，保留“自动选择最佳电路”，点击“拟合”。计算在后台进行，可查看进度或取消。

程序检查从本机 ZSimpWin 清单整理的全部 112 个电路，用多个初值优化，并继续精修候选。所有模型使用相同的频率、阻抗数据和加权方式。推荐依据 AICc；与最小 AICc 相差不超过 2 的候选，优先选择参数较少、估计较稳定的电路。

结果包含电路图、拟合线、元件参数及标准误差。候选表可切换查看其他已收敛电路；“手动选择”提供全部模型的搜索和选择。参数名称沿用元件编号，含义结合电路结构和实验条件解释。

“导出拟合报告”保存所选参数、原始数据来源、完整点序和频率、逐点残差、候选排名与搜索预算。原始曲线继续保留采集顺序和虚部符号。保存 .fri 项目后，重开会按保存的自动或手动设置重新计算。

电路表达式、18 类元件定义与原软件数值对照记录见 [模型来源说明](eis-zsimp-models.md)。
